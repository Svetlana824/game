**Игра «Найди пару» (Matching Game)**

Классическая игра на тренировку памяти и внимательности, написанная на C# с использованием Windows Forms. Ваша задача — найти все пары одинаковых скрытых значков за минимальное количество попыток.

**Описание:**

На игровом поле расположено 16 ячеек, за каждой из которых скрывается один из 8 уникальных значков (каждый значок встречается ровно дважды). Изначально все значки скрыты. Игрок должен открывать по две ячейки за раз, запоминая их расположение, чтобы находить совпадающие пары. 


**Правила игры**
1. Начало игры: При запуске приложения все 16 значков скрыты (их цвет сливается с цветом фона). <img width="546" height="591" alt="image" src="https://github.com/user-attachments/assets/77d69eac-80b6-4640-b387-9c16842f1ba9" />
2. Первый клик: Нажмите на любую ячейку, чтобы открыть скрытый под ней значок. <img width="528" height="568" alt="image" src="https://github.com/user-attachments/assets/7a16b52c-bfc5-4ec3-a994-59092c70d084" />
3. Второй клик: Нажмите на вторую ячейку.
Если значки совпали: Обе клетки остаются открытыми. Вы можете делать следующий ход.
<img width="539" height="584" alt="image" src="https://github.com/user-attachments/assets/edfcdee8-c0fe-422e-b626-f10d8269405f" />

Если значки не совпали: Игра запомнит ваш выбор, после чего обе ячейки автоматически скроются обратно через короткую задержку. 

5. Ограничения:
Вы не можете нажать на ячейку, которая уже была открыта и совпала (она уже черная).
Пока таймер скрывает неудачно открытую пару, новые клики игнорируются.

**Как запустить**

1. Откройте этот код в Visual Studio (как проект Windows Forms).
2. Нажмите F5 или кнопку Запуск.
3. Важно: Убедитесь, что в свойствах всех меток (Label) в конструкторе форм выбран шрифт Webdings. Иначе вместо значков вы будете видеть обычные буквы, так как код использует именно этот шрифт для отображения картинок.
